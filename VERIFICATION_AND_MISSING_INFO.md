## Evidence levels
Use these five levels everywhere in this set. Do not mix them.
- Verified implementation: the actual code, SQL, notebook, or .pbix was inspected and matches the claim.
- Verified execution results: the code, query, or test was actually run and its output was supplied and checked.
- Documented reference values: numbers or descriptions stated in a user-supplied document, not yet checked against a run or a query output.
- Suggested engineering practices: a method, checklist, template, or recommendation to follow, not a claim that it was done.
- Items still requiring evidence: a claim or item with no supplied evidence yet. This is the same meaning as PENDING EVIDENCE in earlier files.
