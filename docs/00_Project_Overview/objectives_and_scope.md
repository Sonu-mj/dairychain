# Objectives and Scope

> Status: PARTIALLY VERIFIED

## Purpose
This file answers what DairyChain set out to do and where its boundary sits. It is for a reader who needs to check whether a claim belongs inside the project or outside it.

## In this file
- The seven objectives
- In scope
- Out of scope
- Intended period and conventions

## The seven objectives
1. Analyse milk procurement across suppliers, districts and collection centres.
2. Measure milk quality and identify rejection patterns.
3. Monitor production batches, input quantities and finished output.
4. Evaluate product-level sales and revenue performance.
5. Analyse order fulfilment and cancelled orders.
6. Create a structured analytical data model for reporting.
7. Convert operational data into meaningful business insights.

## In scope
Data ingestion from CSV, relational processing in PostgreSQL, analytical SQL, Bronze, Silver and Gold layers, and Power BI reporting on four pages. The supplied numbers cover procurement, quality, production and sales.

## Out of scope
Cloud deployment, automated orchestration, real-time streaming, production monitoring and enterprise-scale security are not claimed as implemented. Forecasting is not claimed. The README does not describe wastage, returns, inventory expiry, outlet expenses or energy analysis as part of DairyChain, so those topics are marked NOT IMPLEMENTED in the Q and A folder.

## Intended period and conventions
- Analysis period: 1 Nov 2025 to 31 Oct 2026. Status: INTENDED, TO VERIFY. This comes from the brief, not from a supplied data file or query output.
- Timezone: Asia/Kolkata. Currency: INR. Status: INTENDED, TO VERIFY, on the same basis.
