# Analytics Terms


## Purpose
This file answers what the analytics words in DairyChain mean, with the formula where one exists. It is for a reader who needs to check a KPI name before quoting its value.

## In this file
- Terms
- Formulas

## Terms
- KPI: key performance indicator, a defined measure with a formula.
- Grain: the level of detail of a table, such as one row per batch, per supplier, per product or per day.
- Aggregation: combining rows into a summary, such as a sum or an average, at a stated grain.
- CTE: common table expression, a named temporary result in a SQL query.
- Conditional aggregation: aggregating only the rows that meet a condition, such as only rejected batches.
- Rejection rate: rejected amount divided by total amount, times 100, by count or by volume.
- Fulfilment rate: quantity fulfilled divided by quantity ordered, times 100.
- Yield: finished output divided by relevant raw material input, times 100.
- Margin: profit divided by net revenue, times 100.
- FEFO: first-expired, first-out, using the lot that expires first.
