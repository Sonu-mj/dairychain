# Technical Terms


## Purpose
This file answers what the technical words in DairyChain mean, in plain language. It is for a reader who needs the stack and the layers without a tutorial.

## In this file
- Terms
- Layers

## Terms
- Python: the programming language used for ingestion and processing.
- Pandas: a Python library for data manipulation and transformation.
- PostgreSQL: the relational database used for storage and SQL analysis.
- SQL: the language used to query and transform data in PostgreSQL.
- Power BI: the business intelligence tool used for interactive reporting.
- DAX: Data Analysis Expressions, the formula language for Power BI measures.
- CSV: comma-separated values, a plain-text file format for data exchange.
- Parquet: a columnar file format for analytical processing.
- Git and GitHub: version control and project hosting for code and documentation.

## Layers
- Bronze: ingested source data, as it arrived.
- Silver: cleaned and structured data, ready for analysis.
- Gold: analytical tables built for reporting.
- Medallion architecture: the Bronze, Silver and Gold layer design. In DairyChain, the layers are described in the README.
