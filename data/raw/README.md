# Raw data

This folder holds the 10 source CSV files the project was built from, 99,584 records in total. The files are present in this repo.

## The dataset is synthetic

This is a synthetic dataset, not real operational dairy data. It was generated by `generate_dairychain.py` (in `data/`, version 2.1.1-generated, deterministic seed 42) on 2026-11-09, simulating an Indian dairy factory for the period 2025-11-01 to 2026-10-31. Names, prices, rates, yields, and volumes are generated values. Do not treat them as real-world operating benchmarks. The modelling assumptions are listed in `data/README.md` and in `docs/00_Project_Overview/`.

## Intentional data-quality scenarios

Five data-quality problems were deliberately built into the data by the generator, so the cleaning and validation work can be shown against known faults. They are documented in `data/manifests/manifest.json` and in the validation report at `data/validation_report.txt`:

- DQ-01: suppliers SUP-0015, lowercase status value (`active`).
- DQ-02: suppliers SUP-0042, leading and trailing whitespace in village (` Boriavi `).
- DQ-03: milk_procurement PRC-000500, non-ISO timestamp (`10/11/2025 19:19`).
- DQ-04: milk_procurement PRC-001000, total purchase cost inflated by 25 percent.
- DQ-05: quality_tests QCT-000250, NULL temperature_c.

## Supporting files

- `data/manifests/manifest.json` - row counts, file sizes, keys, DQ scenarios, and validation results for all 10 files.
- `data/validation_report.txt` - 29 checks, Status PASS.
- `data/DATA_DICTIONARY.md` - column meanings for all 10 files.
- `data/SHA256SUMS.txt` - checksums for all 10 files.
- `data/generate_dairychain.py` - the generator that produced these files.
- `docs/13_Project_Evidence/DairyChain_dataset_full.zip` - the original dataset ZIP, kept as evidence.

## What this does NOT prove

These CSVs were supplied as files. They were not loaded into PostgreSQL by any evidenced step. The Bronze load into the database is still not evidenced. The database already exists and its tables were verified separately (see `docs/13_Project_Evidence/`), but how and when the CSV data got into Bronze is still an open question.
